# nifi_kafka

## Instalaciones previas
- Apache Nifi 2.9
  Descomprimimos y renombramos la carpeta a nifi

  ### Levantar servicio de Nifi
  
- Apache Kafka
  Descomprimimos y renombramos la carpeta a kafka

  ### Levantar servicio de Kafka
  
- Elasticsearch
  Descomprimimos y renombramos la carpeta a elasticsearch

  ### Levantar servicio de Elasticsearch

## Creacion de repositorio en GITHub
Se crea el repositorio dentro de github y se genera token en settingd/developer/token(clasic)

## Servicio Controlador de Versiones
Se usa en Nifi el servicio para control de versiones GitHubFlowRegistryClient 2.9.0 usando el token generado
